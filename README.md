# Rogeriopvl Tap

## How do I install these formulae?

`brew install rogeriopvl/tap/<formula>`

Or `brew tap rogeriopvl/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "rogeriopvl/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
